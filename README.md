# 114_prj_game

## Implementation and visualization 114 project- smart parking system

## Modes Description

### 1. Manual Mode – `main.py`
This mode allows manual control of the parking environment. The user can interact step-by-step with the system.

**Features:**
- Visualize movement manually
- Useful for debugging and educational purposes

### 2. Kiva Mode – `mainKiva.py`
Simulates an automated multi-agent parking system inspired by Kiva robots. Robots follow optimized paths to reach their target positions with no collisions.

**Features:**
- Multi-agent coordination
- Collision avoidance logic
- Automatic scheduling and execution

### 3. Puzzle Mode – `mainPuzzle.py`
This mode treats the parking system as a sliding puzzle. It uses pathfinding and search algorithms to solve complex rearrangements in a constrained space.

**Features:**
- Sliding puzzle logic
- Heuristic-based solvers
- Useful for solving static rearrangement problems

## Data Format

All graph input files should be placed in the `./data_graphform/`
